# 🏗️ CBM Build

A modern and professional website developed for **CBM – Construction & Building Management**.

This project presents the company's services, projects, and information through a clean and responsive web interface.

## 🌐 Live Demo

👉 https://www.cbmbuild.com/

## ✨ Features

* 🏠 Modern home page
* 🏢 Company presentation
* 🛠️ Services section
* 📋 Projects showcase
* 📩 Contact section
* 📱 Responsive design
* 🎨 Clean and professional UI
* ⚡ Fast and user-friendly navigation

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **JavaScript**
* **Responsive Web Design**

## 📄 Website Sections

* **Home** — Introduction to CBM and its activities
* **About** — Information about the company
* **Services** — Construction and building management services
* **Projects** — Presentation of completed and ongoing projects
* **Contact** — Contact information and communication section

## 🎯 Project Objective

The main objective of this project is to create a professional online presence for CBM and present its services and projects in a clear and attractive way.
